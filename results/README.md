# Resultados

`scripts/run_benchmarks.sh` guarda ejecuciones locales en `results/runs/`.
Cada lote contiene los parámetros, metadatos y la salida original de cada
repetición. Esa carpeta está ignorada para no mezclar mediciones exploratorias
con los resultados que se seleccionen para la entrega.

Cuando se definan las instrucciones completas, las tablas y figuras finales
pueden guardarse aquí junto con la referencia al lote que las produjo.
