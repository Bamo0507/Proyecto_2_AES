# Resultados de las pruebas

Esta carpeta reúne las mediciones y comparaciones del proyecto.

Los programas de `scripts/` guardan cada grupo de ejecuciones en una carpeta
propia dentro de `results/runs/`. Allí quedan los tiempos, los datos usados,
la información de la máquina y los mensajes que mostró cada programa. La
comparación de las versiones distribuidas también guarda una tabla CSV que se
puede abrir en una hoja de cálculo.

`results/runs/` está excluida de Git para que las pruebas locales no se agreguen
por accidente a la entrega. Las tablas y figuras que se elijan para el informe
pueden guardarse directamente en `results/`, indicando de qué mediciones salieron.
